# v0.4.0: 知识库集成

## Context
v0.3.0 完成了独立服务（gRPC + 配置加载 + Redis 会话存储）。
本阶段实现知识库集成，使 Agent 能够检索知识库内容作为回复的信息基础。
这是 "准确性优先" 约束的核心支撑——RAG 必须执行，检索不到时转人工。

`crates/core/src/traits.rs` 已声明 `VectorStore`、`EmbeddingClient`、`KnowledgeStore` 三个 trait，
但尚无具体实现。本里程碑补全实现并接入工具链路。

版本类型：minor（新增知识库检索能力，向后兼容）

## 产品边界
- 实现内存版 `VectorStore`（余弦相似度检索）
- 实现 `EmbeddingClient`（OpenAI + Mock）
- 实现知识库检索工具 `KnowledgeSearchTool`，串联 Embedding → VectorStore → 结果
- 通过 Cargo feature 支持可选的 Qdrant 向量库实现
- 将知识库工具接入 Agent 工具链路（server 启动示例）

**不做什么**：
- 不实现知识库内容的采集/预处理（OCC 职责，seat-agent 只消费向量）
- 不实现 Qdrant 服务端部署（仅需客户端实现，feature 可选启用）
- 不实现意图分类（按设计决策，工具直接注册，LLM 自行选择）

- **功能目标**：提供进程内的向量存储与相似度检索，作为默认/测试实现
- **文件结构**：创建 `crates/core/src/vector_store.rs`
- **接口设计**：实现 `traits.rs` 已有的 `VectorStore` trait
  ```rust
  // 与设计文档 §17.5 一致命名为 InMemoryVectorStore
  pub struct InMemoryVectorStore {
      // id -> (embedding, metadata)
  }

  impl InMemoryVectorStore {
      pub fn new() -> Self;
      fn cosine_similarity(a: &[f32], b: &[f32]) -> f32;
  }

  #[async_trait]
  impl VectorStore for InMemoryVectorStore {
      async fn upsert(&self, id: &str, embedding: &[f32], metadata: HashMap<String, Value>) -> Result<()>;
      async fn search(&self, embedding: &[f32], limit: usize) -> Result<Vec<SearchResult>>;
      async fn delete(&self, id: &str) -> Result<()>;
      async fn count(&self) -> Result<usize>;
  }
  ```
- **实现要点**：
  - 使用 `RwLock<HashMap<String, (Vec<f32>, HashMap<String, Value>)>>` 保证并发安全
  - `search` 计算余弦相似度，按分数降序返回前 `limit` 个
  - `metadata` 透传，`SearchResult.id`/`score`/`metadata` 来自 trait 定义
  - **放置说明**：设计文档 §17.6 将实现放在 `crates/server`，但本里程碑遵循
    `AGENTS.md` 硬性约束「core crate 零外部依赖」将零依赖的内存实现放在 core，
    外部依赖实现（Qdrant/OpenAI）放在 tools，更契合现状。
  - **签名说明**：设计文档 §17.5 的 `search` 带有 `filter: Option<Filter>` 参数，
    但当前 `traits.rs` 的 `VectorStore::search` 无该参数；本里程碑按实际 trait 实现，

### 2 实现 EmbeddingClient

- **功能目标**：将查询文本转换为向量，供 VectorStore 检索
- **文件结构**：创建 `crates/tools/src/embedding.rs`（实现依赖 reqwest，放 tools 而非 core）
- **接口设计**：实现 `traits.rs` 已有的 `EmbeddingClient` trait
  ```rust
  // OpenAI Embedding 实现
  pub struct OpenAiEmbeddingClient {
      client: reqwest::Client,
      api_key: String,
      model: String,
      base_url: String,
  }

  // Mock 实现（测试用，可配置固定维度）
  pub struct MockEmbeddingClient {
      dim: usize,
      // 可选种子，保证可复现
  }
  ```
- **实现要点**：
  - `OpenAiEmbeddingClient`：POST `{base_url}/embeddings`，解析 `data[].embedding`
  - `MockEmbeddingClient`：基于文本哈希/索引生成确定性伪向量，便于测试断言
  - 两个实现均 `Send + Sync`，满足 trait 约束
- **提交信息**：`feat(tools): implement OpenAI and mock EmbeddingClient`

### 3 实现知识库检索工具 KnowledgeSearchTool

- **功能目标**：作为 Agent 可调用的工具，执行 "embed 查询 → 向量检索 → 格式化结果" 全流程
- **文件结构**：创建 `crates/tools/src/knowledge.rs`
- **接口设计**：实现 `traits.rs` 的 `Tool` trait
  ```rust
  pub struct KnowledgeSearchTool {
      vector_store: Arc<dyn VectorStore>,
      embedding_client: Arc<dyn EmbeddingClient>,
      top_k: usize,
  }

  impl Tool for KnowledgeSearchTool {
      async fn execute(&self, args: Value) -> Result<String>;
  }
  ```
- **实现要点**：
  - `definition()` 复用 `registry.rs` 中 `example_tool_config()` 的 `knowledge_search` 结构
    （name/description/parameters/intermediate_reply/error_reply 保持一致）
  - `execute`：`args["query"]` → `embedding_client.embed(&[query])` →
    `vector_store.search(embedding, top_k)` → 将 `SearchResult` 序列化为带 score+content 的文本
  - metadata 中取出 `content` 字段作为知识正文；无结果返回明确提示（不编造）
  - 错误时返回 `error_reply` 文案，由上层决定是否转人工
- **提交信息**：`feat(tools): implement KnowledgeSearchTool`

### 4 Qdrant 向量库实现（feature 控制）

- **功能目标**：提供生产可用的分布式向量检索实现，按需启用
- **文件结构**：创建 `crates/tools/src/qdrant_store.rs`，在 `crates/tools/Cargo.toml` 增加 `qdrant` feature
- **接口设计**：实现 `VectorStore` trait
  ```rust
  #[cfg(feature = "qdrant")]
  pub struct QdrantVectorStore {
      client: qdrant_client::Qdrant,
      collection: String,
  }
  ```
- **实现要点**：
  - 在 `crates/tools/Cargo.toml` 增加：
    ```toml
    [features]
    default = []
    qdrant = ["qdrant-client"]

    [dependencies]
    qdrant-client = { version = "1", optional = true }
    ```
  - `upsert` 映射为 Qdrant upsert points；`search` 映射为 search points（余弦距离）
  - 该实现仅在 `qdrant` feature 启用时编译，默认构建不受影响
- **提交信息**：`feat(tools): add Qdrant VectorStore behind feature flag`

### 5 接入 Agent 工具链路 + 验证

- **功能目标**：将知识库工具接入 server 启动流程，并验证全链路编译/测试通过
- **文件结构**：修改 `crates/server/src/main.rs`（或新增 builder），`examples/basic_chat` 可选示例
- **接口设计**：
  ```rust
  // main.rs 启动时在 ToolRegistry 注册 knowledge_search
  let vector_store = Arc::new(InMemoryVectorStore::new());
  let embedding = Arc::new(MockEmbeddingClient::new(384));
  let mut registry = ToolRegistry::new();
  registry.register(Box::new(KnowledgeSearchTool::new(
      vector_store, embedding, 3,
  )));
  ```
- **实现要点**：
  - 预置若干示例知识向量，使 basic_chat 能演示检索
  - 确保 `cargo check --workspace`、`cargo clippy --workspace --all-targets -- -D warnings`、
    `cargo test --workspace` 全部通过
- **提交信息**：`feat(server): wire KnowledgeSearchTool into agent startup`
