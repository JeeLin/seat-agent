## 子任务详细设计

### 1 实现 OpenAiClient

- **功能目标**：实现 LlmClient trait，支持 OpenAI API 流式输出
- **文件结构**：创建 `crates/server/src/llm.rs`
- **接口设计**：
  ```rust
  pub struct OpenAiClient {
      api_key: String,
      base_url: String,
      model: String,
  }
  
  #[async_trait]
  impl LlmClient for OpenAiClient {
      async fn chat(&self, request: LlmRequest) -> Result<Pin<Box<dyn Stream<Item = Result<LlmStreamChunk>> + Send>>>;
  }
  ```
- **实现要点**：
  - 使用 reqwest 发送 HTTP 请求
  - 解析 SSE 流式响应
  - 支持 tool_calls 解析
- **提交信息**：`feat(server): implement OpenAI LLM client with streaming`
