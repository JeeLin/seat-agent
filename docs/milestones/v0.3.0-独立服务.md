## 子任务详细设计

### 1 定义 gRPC proto 文件

- **功能目标**：定义 Agent 服务的 gRPC 接口
- **文件结构**：创建 `proto/seat_agent.proto`
- **接口设计**：
  ```protobuf
  syntax = "proto3";
  package seat_agent;
  
  service AgentService {
    rpc Chat(stream ChatRequest) returns (stream ChatResponse);
  }
  
  message ChatRequest {
    string session_id = 1;
    oneof message {
      TextMessage text = 2;
    }
  }
  
  message TextMessage {
    string content = 1;
  }
  
  message ChatResponse {
    string session_id = 1;
    oneof event {
      TokenEvent token = 2;
      ToolCallEvent tool_call = 3;
      TransferEvent transfer = 4;
      ErrorEvent error = 5;
    }
  }
  
  message TokenEvent {
    string content = 1;
  }
  
  message ToolCallEvent {
    string tool_name = 1;
    string arguments = 2;
  }
  
  message TransferEvent {
    string reason = 1;
  }
  
  message ErrorEvent {
    string message = 1;
  }
  ```
- **提交信息**：`feat(server): define gRPC proto for Agent service`

### 2 实现 Redis 会话存储

- **功能目标**：实现 SessionStore trait，使用 Redis 存储会话
- **文件结构**：创建 `crates/server/src/redis_store.rs`
- **接口设计**：
  ```rust
  pub struct RedisSessionStore {
      client: redis::Client,
  }
  
  #[async_trait]
  impl SessionStore for RedisSessionStore {
      async fn get(&self, session_id: &str) -> Result<Option<Session>>;
      async fn set(&self, session_id: &str, session: &Session) -> Result<()>;
      async fn delete(&self, session_id: &str) -> Result<()>;
  }
  ```
- **实现要点**：
  - 使用 redis crate 连接 Redis
  - 序列化/反序列化 Session 结构
  - 支持 TTL 过期
- **提交信息**：`feat(server): implement Redis session store`

### 4 实现 gRPC server

- **功能目标**：实现 gRPC Bidi Streaming server
- **文件结构**：创建 `crates/server/src/grpc.rs`
- **接口设计**：
  ```rust
  pub struct AgentGrpcServer {
      agent: Agent,
      session_store: Box<dyn SessionStore>,
  }
  
  #[tonic::async_trait]
  impl AgentService for AgentGrpcServer {
      type ChatStream = Pin<Box<dyn Stream<Item = Result<ChatResponse>> + Send>>;
      
      async fn chat(
          &self,
          request: Request<Streaming<ChatRequest>>,
      ) -> Result<Response<Self::ChatStream>>;
  }
  ```
- **实现要点**：
  - 使用 tonic 实现 gRPC
  - 将 AgentEvent 转换为 ChatResponse
  - 支持双向流式
- **提交信息**：`feat(server): implement gRPC server with streaming`
