# v1.0.0: 生产就绪

## Context
v0.1.0-v0.6.0 逐步构建了 seat-agent 的核心架构：Agent Loop、Context 分层、工具注册、LLM 集成、gRPC 服务、知识库检索、业务工具、测试和示例。v1.0.0 聚焦于填补生产环境所需的缺口：记忆系统实现、服务端完整接入、API 文档。
版本类型：major（首个正式发布版本）

## 产品边界

**本阶段做什么：**
- 实现 memory crate（短期记忆、长期记忆、会话摘要）
- server crate 接入 memory 和 embedding
- 公共 API 文档完善
- 端到端集成测试

**本阶段不做什么：**
- 监控与可观测性（tracing/metrics）— 留给 OCC 自身
- TTS client 实现 — 依赖 OCC 侧 ASR/TTS 基础设施
- 前端界面 — OCC 负责
- 多租户/权限 — OCC RLS 层负责

## 子任务详细设计
| 1 | 记忆模块：短期记忆（滑动窗口截断） + 长期记忆（向量检索历史摘要） + 会话摘要生成/修正 | ✅ |
### 1 Memory crate 实现

- **功能目标**：实现短期记忆（滑动窗口截断）、长期记忆（向量检索历史摘要）、会话摘要生成/修正
- **文件结构**：
  - `crates/memory/src/lib.rs` — re-export
  - `crates/memory/src/short_term.rs` — ShortTermMemory（滑动窗口 + token 预算）
  - `crates/memory/src/long_term.rs` — LongTermMemory（依赖 VectorStore trait 做向量检索）
  - `crates/memory/src/summary.rs` — SummaryGenerator（依赖 LlmClient 生成摘要）
  - `crates/memory/src/tests.rs`（或 inline）— 单元测试
- **接口设计**：
  ```rust
  pub struct ShortTermMemory { max_messages: usize }
  impl ShortTermMemory {
      pub fn new(max_messages: usize) -> Self;
      pub fn trim(&self, history: &[Message]) -> Vec<Message>;
  }

  pub struct LongTermMemory<V: VectorStore> { store: V }
  impl<V: VectorStore> LongTermMemory<V> {
      pub fn new(store: V) -> Self;
      pub async fn search(&self, query: &str, top_k: usize) -> Result<Vec<SearchResult>>;
  }

  pub struct SummaryGenerator<L: LlmClient> { llm: L }
  impl<L: LlmClient> SummaryGenerator<L> {
      pub fn new(llm: L) -> Self;
      pub async fn generate(&self, history: &[Message], existing: Option<&str>) -> Result<String>;
  }
  ```
- **后端流程**：short_term 在每轮 Agent Loop 开始时 trim history；long_term 在会话开始时检索历史摘要注入 context；summary 在会话结束时异步生成
- **测试标准**：short_term 正确截断、long_term 正确检索、summary 正确生成；边界：空历史、单条历史、超长历史
- **提交信息**：`feat(memory): implement short-term, long-term memory and summary generation`

### 2 Server crate 接入 memory

- **功能目标**：在 server 启动时初始化 memory 组件，注入 Agent Loop
  - `crates/server/src/config.rs` — 添加 MemoryConfig（short_term max_messages, summary model 等）
  - `crates/server/src/main.rs` — 接入 memory crate（初始化 short_term + long_term + summary）
  - 复用已有的 `redis_store.rs`（MemoryStore）和 tools 的 `OpenAiEmbeddingClient`
- **接口设计**：server 使用 config 中的 memory 配置初始化 short_term + long_term，通过 Context 注入 Agent
- **后端流程**：启动 → 加载配置 → 初始化 embedding → 初始化 vector store → 初始化 memory → 创建 Agent → 启动 gRPC server
- **测试标准**：server 编译通过、启动不 panic、配置加载正确
- **提交信息**：`feat(server): wire memory crate into agent startup`

### 3 公共 API 文档

- **功能目标**：为所有 lib crate 的公共 API 添加 rustdoc，添加 crate-level 文档
- **文件结构**：修改 `crates/*/src/lib.rs` 和公共类型
- **文档内容**：
  - crate-level：简介 + 使用示例（从 examples 中提取）
  - 公共 struct/enum/trait：功能描述 + 使用示例
  - 公共方法：参数说明 + 返回值说明
- **测试标准**：`cargo doc --workspace --no-deps` 无 warning
- **提交信息**：`docs: add rustdoc for public APIs`

### 4 端到端集成测试

- **功能目标**：验证 server 从配置加载到 gRPC 请求处理的完整链路
- **文件结构**：`crates/server/tests/server_integration.rs`
- **测试场景**：
  1. 配置加载 → server 组件正确初始化
  2. Agent + tools 完整对话流程（mock LLM）
  3. 短期记忆截断生效
- **测试标准**：测试编译通过、mock LLM 场景下完整流程可跑通
- **提交信息**：`test(server): add end-to-end integration tests`
