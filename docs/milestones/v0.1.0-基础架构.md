### 2 实现 core/src/traits.rs（核心 trait 定义）

- **功能目标**：定义所有核心 trait，作为 crate 间的抽象层
- **文件结构**：`crates/core/src/traits.rs`
- **接口设计**：
  ```rust
  #[async_trait]
  pub trait LlmClient: Send + Sync {
      async fn chat_stream(&self, request: LlmRequest) -> Result<BoxStream<'static, LlmStreamChunk>>;
  }

  #[async_trait]
  pub trait KnowledgeStore: Send + Sync {
      async fn search(&self, query: &str, limit: usize) -> Result<Vec<KnowledgeResult>>;
  }

  #[async_trait]
  pub trait MemoryStore: Send + Sync {
      async fn save(&self, key: &str, value: &str, ttl: Option<Duration>) -> Result<()>;
      async fn load(&self, key: &str) -> Result<Option<String>>;
      async fn delete(&self, key: &str) -> Result<()>;
  }

  #[async_trait]
  pub trait VectorStore: Send + Sync {
      async fn upsert(&self, id: &str, embedding: &[f32], metadata: HashMap<String, Value>) -> Result<()>;
      async fn search(&self, embedding: &[f32], limit: usize) -> Result<Vec<SearchResult>>;
      async fn delete(&self, id: &str) -> Result<()>;
  }

  #[async_trait]
  pub trait Tool: Send + Sync {
      fn definition(&self) -> ToolDefinition;
      async fn execute(&self, args: serde_json::Value) -> Result<String>;
  }
  ```
- **测试标准**：`cargo check -p seat-agent-core` 通过
- **提交信息**：`feat(core): define core traits (LlmClient, KnowledgeStore, MemoryStore, VectorStore, Tool)`

### 3 实现 core/src/config.rs（AgentConfig）

- **功能目标**：定义 Agent 配置结构，支持 Default trait
- **文件结构**：`crates/core/src/config.rs`
- **接口设计**：
  ```rust
  #[derive(Debug, Clone, Serialize, Deserialize)]
  pub struct AgentConfig {
      pub modality: Modality,
      pub max_rounds: usize,
      pub max_duration: Duration,
      pub max_output_tokens: usize,
      pub min_history_messages: usize,
      pub total_token_limit: usize,
      pub system_prompt: Option<String>,
  }

  #[derive(Debug, Clone, Serialize, Deserialize)]
  pub enum Modality {
      Text,
      Voice,
  }

  impl Default for AgentConfig {
      fn default() -> Self {
          Self {
              modality: Modality::Text,
              max_rounds: 10,
              max_duration: Duration::from_secs(30),
              max_output_tokens: 500,
              min_history_messages: 2,
              total_token_limit: 8000,
              system_prompt: None,
          }
      }
  }
  ```
- **测试标准**：`cargo check -p seat-agent-core` 通过
- **提交信息**：`feat(core): implement AgentConfig with Default trait`

### 4 实现 core/src/error.rs（错误类型）

- **功能目标**：定义统一错误类型，支持 From trait 转换
- **文件结构**：`crates/core/src/error.rs`
- **接口设计**：
  ```rust
  #[derive(Debug, thiserror::Error)]
  pub enum AgentError {
      #[error("LLM error: {0}")]
      Llm(String),

      #[error("Tool error: {0}")]
      Tool(String),

      #[error("Knowledge store error: {0}")]
      Knowledge(String),

      #[error("Memory store error: {0}")]
      Memory(String),

      #[error("Timeout after {0:?}")]
      Timeout(Duration),

      #[error("Max rounds exceeded: {0}")]
      MaxRoundsExceeded(usize),

      #[error("Configuration error: {0}")]
      Config(String),

      #[error("Internal error: {0}")]
      Internal(String),
  }

  pub type Result<T> = std::result::Result<T, AgentError>;
  ```
- **测试标准**：`cargo check -p seat-agent-core` 通过
- **提交信息**：`feat(core): implement unified error types`

- **接口设计**：

  pub struct Context {
      pub session_id: String,
      pub modality: Modality,
      pub system: Vec<Message>,
      pub retrieval: Vec<KnowledgeResult>,
      pub history_summary: Option<String>,
      pub history: Vec<Message>,

  impl Context {

- **测试标准**：单元测试覆盖 token 计算和截断逻辑
- **提交信息**：`feat(core): implement Context with layered model and token budget`

### 6 实现 core/src/agent.rs（Agent Loop）

- **功能目标**：实现消息队列消费模型 + Agent 主循环
- **文件结构**：`crates/core/src/agent.rs`
- **接口设计**：
  ```rust
  pub struct Agent {
      config: AgentConfig,
      llm: Box<dyn LlmClient>,
      tools: Vec<Box<dyn Tool>>,
      knowledge: Option<Box<dyn KnowledgeStore>>,
      memory: Option<Box<dyn MemoryStore>>,
  }

  impl Agent {
      pub fn new(config: AgentConfig, llm: Box<dyn LlmClient>) -> Self;
      pub fn register_tool(&mut self, tool: Box<dyn Tool>);
      pub fn set_knowledge(&mut self, knowledge: Box<dyn KnowledgeStore>);
      pub fn set_memory(&mut self, memory: Box<dyn MemoryStore>);

      pub async fn on_message(
          &self,
          input: AgentInput,
          output_tx: tokio::sync::mpsc::Sender<AgentEvent>,
      ) -> Result<()>;
  }

  pub struct AgentInput {
      pub session_id: String,
      pub message: Message,
  }

  pub enum AgentEvent {
      StreamStart,
      Token(String),
      StreamEnd,
      ToolCallStart { tool_name: String, arguments: String },
      ToolCallEnd { tool_name: String, result: String },
      TransferToHuman { reason: String },
      Error(String),
  }
  ```
- **测试标准**：使用 mock LLM 运行完整 Agent Loop
- **提交信息**：`feat(core): implement Agent Loop with message queue model`

  pub struct ToolRegistry {
      tools: HashMap<String, Box<dyn Tool>>,
      configs: Vec<ToolConfig>,

  #[derive(Debug, Clone, Serialize, Deserialize)]
  pub struct ToolConfig {
      pub name: String,
      pub display_name: String,
      pub description: String,
      pub category: String,
      pub enabled: bool,
      pub sensitive: bool,
      pub parameters: serde_json::Value,

  impl ToolRegistry {

- **测试标准**：从 JSON 加载工具配置，验证工具注册
